# Contributing

Start from the default branch and use a focused feature branch. See [development](docs/development.md) for local commands. Include deterministic tests for changes to status classification, IPC, exports and storage. Use fixtures for routine tests. Live searches require a synthetic or explicitly authorized account.

Describe user-facing changes and platform coverage in the pull request. For a dependency update, refresh the matching lockfile and check licenses. Changes to website access must continue to honor TLS verification, rate limits, login boundaries and access restrictions.
