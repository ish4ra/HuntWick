# Sherlock integration

HuntWick uses the MIT-licensed [`sherlock-project` 0.16.2 release](https://github.com/sherlock-project/sherlock/tree/a38ba54fda799cd786a2ab67a50143e1a63169e6). It calls `sherlock_project.sherlock.sherlock()` and `SitesInformation` from this package. Desktop retains the upstream verdict and request method. Enhanced Search substitutes a native public lookup on selected platforms. The hosted allowlist uses its separate evidence policy. The [upstream usage documentation](https://sherlockproject.xyz/usage) describes the standalone Sherlock CLI.

`data/sites.json` is the verbatim [upstream site manifest](https://github.com/sherlock-project/sherlock/blob/4e2a4f6b66433849abe46cae76ed557c6c8313c8/sherlock_project/resources/data.json), last changed May 4, 2026. Its contents match the snapshot in the 0.16.2 release. `data/exclusions.txt` comes from the [upstream false-positive exclusion list](https://github.com/sherlock-project/sherlock/blob/109627496bf0afcb18323c5472b50d6fc3785c3a/false_positive_exclusions.txt), reviewed November 25, 2026. The app reports the catalog review date and all three revisions. See [Sherlock-MIT.txt](Sherlock-MIT.txt) for the copyright and license.

The catalog applies Sherlock's standard adult-site exclusions, excludes unsupported or insecure probes and retains read-only HTTPS public-profile rules. HuntWick supplies categories and the Quick selection. Database updates ship with app releases. No manifest download occurs at launch. To refresh a snapshot, review the upstream definitions and exclusions, replace these files, update their digests, revision and date in `catalog.py`, regenerate `public/catalog.json`, then run the engine suite and packaged smoke check.

## Maigret desktop provider

The hash-locked Maigret 0.6.7 wheel supplies the request planner and verdict evaluator. Its MIT-licensed catalog has SHA-256 `99e70fe7167b1c884a221d41f8a1815e40ca1db7a07581b6b401fd590e5b6fa4`. Run `python engine/prepare_maigret.py` in the locked engine environment to reproduce the compiled rule snapshot. The compiler resolves Maigret engine inheritance, selects reviewed profile routes and records exclusion reasons. The runtime calls `make_site_result` and `process_site_result` with parsing disabled, and executes the planned read-only request in HuntWick's supervised TLS transport. See [Maigret upstream](https://github.com/soxoj/maigret) and [the MIT notice](Maigret-MIT.txt).
