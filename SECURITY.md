# Security

For a vulnerability, use GitHub's **Report a vulnerability** option in the repository Security tab when available. If private reporting is unavailable, ask for a private reporting channel in a public issue without posting exploit details, affected usernames, or evidence containing personal information.

Include the HuntWick version, OS and architecture, expected security boundary, and a minimal reproduction using synthetic data. Do not send search histories or information about third parties. The alpha has no guaranteed response time or support period.
