Each study folder also contains a full application sidebar crop (<code>app-sidebar.png</code>) and independent transparent wordmark PNGs for both themes. Each study folder includes individual 16, 24, 32, 64 and 128 px icon PNGs. Open the native-size comparison at 100% to judge the smallest marks. The desktop sidebar images are browser captures of the application header with local artwork overrides. The Dock, taskbar and tab are scale references drawn for review.
